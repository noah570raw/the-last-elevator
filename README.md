# THE LAST ELEVATOR

Стартовый проект Roblox Studio с Luau, Rojo 7.7.1 и Rokit. Содержит технические скрипты для проверки запуска на сервере и клиенте после live sync. Дизайн, задачи и проверяемые критерии находятся в соседнем `NoahVault`.

## Запуск

Открой эту папку в VS Code. `rokit install` устанавливает закреплённые инструменты. `rojo serve` открывает локальный сервер подключения. Из пустого тестового place в Studio выбери **Plugins → Rojo → Connect** и запусти Play. На сервере и клиенте ожидается одна строка с версией. Инструкция целиком — `../NoahVault/00 Command Center/Setup.md`.

Области карты и света остаются в Studio. Перед редактированием прочитай `CLAUDE.md` и роутер в ваулте.
