# THE LAST ELEVATOR — Claude Code

Проект на стадии концепта. Игровая цель — vertical slice на 30–45 минут. Документация на русском, имена систем, файлов и код преимущественно на английском.

## Начало сессии

1. Работа из корня этой папки. Соседний ваулт — `../NoahVault`. Запускай Claude Code с `claude --add-dir '../NoahVault'`.
2. Прочитай `../NoahVault/00 Command Center/ROUTER.md` и карточку задачи. Если задачи нет, открой `Command Center.md` в той же папке.
3. По ссылкам загрузи спецификацию, решение, проверку, затем подходящие участки Luau и несколько кадров. Для обширной задачи уточни, какие источники определяют текущий контракт.
4. Завершай работу короткой сводкой: изменение, проверка, открытый блокер и обновлённые карточки.

## Полномочия

- AI может анализировать, заводить задачи, предлагать решения и обновлять технические записи.
- Изменение утверждённого канона и фундаментальных механик требует согласия владельца. Записывай предложение в Decision и связывай с системой.
- Факты канона находятся в `../NoahVault/03 World and Narrative/CANON-01.md`. Точная формулировка поворота поступит от владельца.
- Справочные старые ваулты, если их добавят отдельно, используются только на чтение. Исключай приватные сведения, секреты и пользовательские данные.

## Реализация и проверка

Luau меняем в `src`. `default.project.json` определяет области Rojo. Перед первым вызовом Studio MCP прочитай `../NoahVault/05 Engineering/Engineering Map.md` и выбери тестовый place по имени. Статус реализации системы повышается после проверки кода и успешного теста в Studio с зафиксированной версией. Требования к полям и статусам — `../NoahVault/00 Command Center/Status Model.md`.

Инструменты и подключение описаны в `../NoahVault/00 Command Center/Setup.md`. Не путай локальную сборку Rojo с запуском игры в Studio.
